# Splunk SOC Detection Lab

Hands-on Splunk detection engineering lab, organised around architecture, detection content, incident reports, dashboards, and MITRE ATT&CK coverage.

## Repository layout

- `architecture/` — lab topology and supporting diagrams
- `dashboards/` — dashboard definitions and exports
- `detections/` — documented detection use cases
- `incident_reports/` — investigation and incident-report artefacts
- `screenshots/` — lab evidence and dashboard captures
- `work/` — working notes and temporary lab artefacts
